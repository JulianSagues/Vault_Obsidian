¿Cómo funciona el sistema?
- El cliente llega con un proyecto el cual quiere llevar a cabo
- Si es su primer proyecto se lo da de alta
- Se realiza un convenio con los servicios que desea el cliente (Tipo servicio) y la cantidad de horas que desea en cada uno
- Si se encuentra al menos a un profesional se aprobara el convenio, en caso contrario quedara rechazado
- Una vez quede aceptado el convenio el cliente si esta conforme podrá firmar para los profesionales puedan empezar a trabajar
- Habrá un monto fijo que se descontara por mes, además de los honorarios y valores de las tareas realizados por cada profesional
- Los profesionales irán presentando los servicios realizados hasta terminar con el trabajo, si el cliente aprueba lo realizado quedaran finalizados y de no ser el caso, los profesionales que no se les ha aprobado sus servicios deberán realizar una iteración
- Una vez terminado el servicio se lo facturara
- El cliente podra cancelar de ser necesario siempre que el proyecto este firmado, en proceso o aceptado, en cuyo caso se le cobrara una multa
